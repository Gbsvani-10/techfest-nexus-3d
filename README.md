## 🚀 About the Project

**TECHFEST NEXUS 3D** is an immersive 3D website designed to transform the traditional browsing experience into an interactive virtual technology universe.

Inspired by futuristic environments and next-generation digital experiences, the project combines real-time 3D graphics, cinematic animations, interactive objects and modern web technologies.

Visitors can explore futuristic environments, discover technology exhibitions, interact with 3D models and experience a creative digital world.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Gbsvani-10/techfest-nexus-3d.git
```

### 2. Navigate to the project directory

```bash
cd techfest-nexus-3d
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

Visit the local development URL displayed in your terminal.

Usually:

```text
http://localhost:5173
```
